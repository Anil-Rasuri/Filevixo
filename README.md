# Filevixo

Filevixo is an online file and image toolkit designed to make common file operations simple and easy to use.

## Features

- Compress Images
- Convert Image Formats
- Resize Images
- Crop Images
- Images to PDF
- Word to PDF
- PDF to Word
- Remove Image Background
- Merge PDF Files

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Python
- FastAPI
- Pillow
- PyPDF2
- python-docx
- ReportLab
- rembg
